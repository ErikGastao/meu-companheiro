# Meu Companheiro

Protótipo de jogo feito em Godot para um público idoso, com uma proposta parecida com o Pou: uma experiência simples, visual e fácil de usar.

## Sobre o projeto

Este repositório contém a base inicial do protótipo, com cenas separadas para ambientes, loja, ajuda, barra superior e inferior, além de elementos como pet, moedas e interface.

## Como abrir no Godot

1. Instale o Godot 4.6 ou superior.
2. Abra a pasta deste projeto no editor.
3. Execute a cena principal definida no projeto ou escolha a cena desejada para teste.

## Como publicar na nuvem

O caminho mais simples é exportar para Web:

1. No Godot, vá em `Project > Export`.
2. Adicione o preset `Web`.
3. Exporte os arquivos do jogo para uma pasta.
4. Publique essa pasta em um serviço como Itch.io, GitHub Pages, Netlify ou Vercel.

## Objetivo do protótipo

- Interface simples e legível
- Navegação fácil para idosos
- Elementos visuais leves e amigáveis
- Base para evoluir com interações do pet e do ambiente
